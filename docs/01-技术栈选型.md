# 立里博客前端重构 - 开发技术栈选型文档

## 1. 选型原则

- **Vue 3 生态**：组合式 API 更灵活，TypeScript 支持更好，性能优秀
- **反算法美学**：拒绝"企业风"和"算法友好"的平滑设计，追求带有摩擦与阻抗的独立审美
- **可定制性**：组件源代码可修改，主题系统完全可控

## 2. 核心技术栈

| 类别 | 技术选型 | 版本 | 说明 |
|------|---------|------|------|
| 前端框架 | **Vue 3** | ^3.5.x | 组合式 API + `<script setup>` |

## 3. 选型理由

### 3.1 为什么选 Vue 3 + Vite

- 组合式 API 逻辑复用更灵活
- `<script setup>` 语法更简洁
- Vite 冷启动极快，开发体验好
- 与 TypeScript 深度集成

### 3.2 为什么选 shadcn-vue + Tailwind CSS

- **拒绝企业风**：Ant Design / Element Plus 太"后台管理系统"风格
- **源代码可定制**：shadcn 组件直接复制到项目中，可任意修改
- **原子化样式**：Tailwind 的 utility-first 方式非常适合快速实现反算法美学
- **主题系统**：CSS 变量驱动，暗色模式切换简单

### 3.3 为什么选 Pinia

- Vue 官方推荐状态管理方案
- TypeScript 友好，类型推断完善
- API 简洁，学习成本低
- 支持组合式 API 风格

### 3.4 为什么选 Axios

- 拦截器机制完善
- 支持请求/响应拦截
- 便于统一处理 Token 刷新和错误处理
- 社区成熟，文档完善
