# 立里博客前端重构 - 页面设计需求文档

## 1. 页面清单

| 页面 | 路由 | 权限 | 功能描述 |
|------|------|------|----------|
| **首页** | `/` | 公开 | Hero 区域 + 文章列表 + 侧边栏 |
| **我的首页** | `/user/me` | 登录用户 | 我的文章（支持状态筛选） |
| **用户首页** | `/user/:id` | 公开 | 指定用户的已发布文章 |
| **文章详情** | `/article/:id` | 公开 | 文章阅读、点赞、评论 |
| **分类文章** | `/category/:id` | 公开 | 按分类筛选文章 |
| **标签文章** | `/tag/:id` | 公开 | 按标签筛选文章 |
| **关于** | `/about` | 公开 | 关于页面（使用文章 ID=1 作为内容） |
| **登录** | `/login` | 公开 | 用户名密码/邮箱验证码登录 |
| **注册** | `/register` | 管理员 | 管理员注册新用户 |
| **后台首页** | `/admin` | 管理员 | 仪表盘 |
| **文章管理** | `/admin/articles` | 管理员 | 文章 CRUD |
| **分类管理** | `/admin/categories` | 管理员 | 分类 CRUD |
| **标签管理** | `/admin/tags` | 管理员 | 标签 CRUD |
| **评论管理** | `/admin/comments` | 管理员 | 评论审核、删除 |
| **用户设置** | `/settings` | 登录用户 | 修改昵称、头像、密码 |
| **写文章** | `/write` | 管理员 | Markdown 编辑器写文章 |
| **编辑文章** | `/write/:id` | 管理员 | 编辑已有文章 |

## 2. 全局布局结构

### 2.1 三栏布局（首页 + 文章列表页 + 文章详情页）

```
┌─────────────────────────────────────────────────────────────────┐

│              │   (文章内全宽展示)              │  └────────────┘  │

│              │                              │                  │
├──────────────┴──────────────────────────────┴──────────────────┤
│  [页脚]                                                         │
│  © 2024 LiliCould's Blog | Powered by ...                       │
└─────────────────────────────────────────────────────────────────┘
```

**布局规则**：
- 三栏布局：左侧边栏(固定宽度) + 中间主内容区(自适应) + 右侧边栏(固定宽度)
- 左侧边栏：作者信息（头像、昵称、简介、社交链接、分类目录、统计）
- 右侧边栏：随机文章、标签云
- **首页特有**：Hero 区域在顶部导航栏下方、三栏布局上方
- **其他页面**：无 Hero 区域，直接使用三栏布局

### 2.2 响应式布局策略

| 断点 | 布局 |
|------|------|
| >= 1280px (xl) | 三栏布局：左侧 280px + 中间自适应 + 右侧 280px |
| >= 1024px (lg) | 三栏布局：左侧 240px + 中间自适应 + 右侧 240px |
| >= 768px (md) | 两栏布局：左侧 240px + 中间自适应（右侧隐藏） |
| < 768px (sm) | 单栏布局：中间内容区（侧边栏隐藏到抽屉） |

**移动端侧边栏**：
- 点击汉堡菜单展开左侧边栏抽屉
- 右侧边栏内容折叠到页面底部

## 3. 各页面详细设计

### 3.1 首页（`/`）

#### Hero 区域

```
┌─────────────────────────────────────────────────────────────────┐
│  Hero 区域（全宽）                                               │
│                                                                  │
│     ┌─────────────────────────────────────────────────────┐     │
│     │  LiliCould's Blog                                   │     │
│     │  <技术与生活的分享空间_/>                             │     │
│     └─────────────────────────────────────────────────────┘     │
│                                                                  │
│  [背景图 + 抖音闪动文字效果 + 打字机效果]                         │
└─────────────────────────────────────────────────────────────────┘
```

**设计要求**：
- 使用指定的静态资源图片作为背景
- 主标题 "LiliCould's Blog"：抖音风格文字闪动动画效果
- 副标题 "<技术与生活的分享空间_/>"：动态打字机效果，逐字输入
- 文字与背景图有良好对比度，保证可读性

#### 下方三栏布局

- 左侧边栏：作者信息卡片 + 分类目录 + 统计信息
- 中间主内容区：文章列表分页展示
- 右侧边栏：随机文章(5篇) + 标签云

**文章列表**：
- 调用接口：GET /api/article?status=1（只展示已发布）
- 文章卡片：封面图、标题、摘要、分类、标签、作者、时间、阅读/点赞/评论数

---

### 3.2 我的首页（`/user/me`）

**功能需求**：
- 展示当前登录用户的文章列表
- 状态筛选标签：全部 / 已发布 / 审核中 / 草稿
- 调用接口：GET /api/article?createBy={currentUserId}&status={status}
- 文章卡片增加状态标识

**状态筛选交互**：
```
┌─────────────────────────────────────────────────┐
│  [全部] [已发布] [审核中] [草稿]                    │
│   ────                                          │
│  点击切换，下划线高亮（毒性色）                      │
└─────────────────────────────────────────────────┘
```

---

### 3.3 用户首页（`/user/:id`）

**功能需求**：
- 展示指定用户的已发布文章
- 调用接口：GET /api/article?createBy={userId}&status=1
- 只展示已发布文章，无状态筛选
- 左侧边栏显示该用户信息（GET /api/user/{id}）

**页面顶部横幅**：
- 使用指定的静态资源图片作为横幅背景
- 横幅下方展示用户信息区域：头像、昵称、邮箱等
- 用户信息区域下方实现文章列表，按时间倒序排列

---

### 3.4 文章详情（`/article/:id`）

**布局**：
```
┌─────────────────────────────────────────────────────────────────┐
│  Header                                                         │
├──────────────┬──────────────────────────────────┬───────────────┤
│  [左侧边栏]   │      [中间主内容区]               │  [右侧边栏]    │
│  作者信息     │                                  │  随机文章      │
│  (该文章作者) │   文章标题（Display 字号）         │  标签云        │
│              │   元信息：时间 · 分类 · 标签       │               │
│              │                                  │               │
│              │   ┌──────────────────────────┐   │               │
│              │   │      封面图（全宽）         │   │               │
│              │   └──────────────────────────┘   │               │
│              │                                  │               │
│              │   ┌──────────────────────────┐   │               │
│              │   │   文章内容（prose 渲染）     │   │               │
│              │   │   Markdown 转 HTML          │   │               │
│              │   │                            │   │               │
│              │   │   图片全宽展示               │   │               │
│              │   │   代码块粗边框               │   │               │
│              │   └──────────────────────────┘   │               │
│              │                                  │               │
│              │   点赞区 · 评论区                 │               │
│              │                                  │               │
└──────────────┴──────────────────────────────────┴───────────────┘
```

**注意**：文章详情页的左侧边栏显示**文章作者**的信息，而非当前登录用户。

**功能需求**：
- 文章详情获取（GET /api/article/{id}）
- 内容渲染：使用 `contentHtml`，配合 prose 样式
- 点赞功能：查询状态（GET /api/article/{id}/like）、点赞（PUT /api/article/{id}/like）、取消点赞（PUT /api/article/{id}/unlike）
- 评论功能：发布评论（POST /api/comment）、获取一级评论（GET /api/comment）、获取二级评论（GET /api/comment/child）

---

### 3.5 关于（`/about`）

**功能需求**：
- 开发关于页面路由，路由路径设置为 "/about"
- 实现通过文章 ID 查询博客文章的功能，使用 ID 为 1 的文章作为关于页面内容
- 在导航栏中添加"关于"导航项，点击后指向 /about 路由
- 调用接口：GET /api/article/1

---

### 3.6 分类文章（`/category/:slug`）

**功能需求**：
- 展示指定分类的文章列表
- 调用接口：GET /api/article?categoryId={id}&status=1
- 页面标题显示分类名称和描述

**分类展示逻辑**：
- 对接分类列表查询接口获取所有分类数据（GET /api/category）
- 当分类数量较少时（<= 8 个），一次性全部展示
- 当分类数量较多时，实现分页或滚动加载机制

---

### 3.7 标签文章（`/tag/:slug`）

**功能需求**：
- 展示指定标签的文章列表
- 调用接口：GET /api/article?status=1（注意：后端暂不支持按标签过滤，当前显示所有文章）
- 页面标题显示标签名称和颜色

---

### 3.8 登录（`/login`）

**布局**：
- 不使用三栏布局
- 居中卡片式登录框
- 背景可添加噪点纹理

**功能需求**：
- 用户名密码登录（POST /auth/login/pwd）
- 邮箱验证码登录（POST /auth/login/email）
- 登录成功后存储 accessToken 到 localStorage，refreshToken 自动在 cookie 中
- 获取用户信息（GET /api/user/me）

---

### 3.9 后台管理（`/admin/*`）

**布局**：
- 不使用三栏布局
- 左侧 Sidebar 导航 + 右侧内容区
- 更紧凑的信息密度

---

### 3.10 写文章（`/write`）

**布局**：
- 不使用三栏布局
- 全宽编辑器
- 顶部工具栏固定

**功能需求**：
- Markdown 编辑（Vditor）
- 实时预览
- 封面图上传（POST /file/upload，type=cover）
- 分类选择下拉（GET /api/category）
- 标签多选（GET /api/tag）
- 保存草稿/发布文章

## 6. 全局组件需求

| 组件 | 用途 | 设计要点 |
|------|------|----------|
| Header | 全局导航 | Logo(毒性色) + 导航链接 + 主题切换按钮 |
| Footer | 页脚 | 版权信息 + 技术栈标识 |
| ArticleCard | 文章卡片 | 粗边框 + 硬阴影 + 直角 |
| CommentItem | 评论项 | 嵌套层级线 + 作者信息 |
| Pagination | 分页器 | 方形按钮 + 硬边框 |
| EmptyState | 空状态 | 机械图标 + 大字提示 |
| LoadingBlock | 加载态 | 像素块填充或打字机效果 |
| ErrorState | 错误态 | 故障艺术风格 |
| ConfirmDialog | 确认弹窗 | 硬边框 + 无圆角 |
| Toast | 消息提示 | 左侧毒性色边框 + 打字机文字 |
| GlitchText | 抖音闪动文字 | 故障艺术动画 |
| TypewriterText | 打字机效果 | 逐字输入动画 |
| SocialLinks | 社交链接 | 四个平台图标 + 悬停效果 |
