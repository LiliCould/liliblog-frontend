## 2. 组件设计模式

### 2.1 原子设计方法论

- **Atoms（原子）**: Button、Input、Badge、Icon 等基础元素 → shadcn-vue 组件
- **Molecules（分子）**: ArticleCard、CommentItem、SocialLinks 等组合组件
- **Organisms（有机体）**: ArticleList、CommentList、HeroSection 等复杂组件
- **Templates（模板）**: MainLayout、AdminLayout 等页面框架
- **Pages（页面）**: HomeView、ArticleDetailView 等完整页面

### 2.2 组件复用策略

- 所有业务组件使用 Composition API + `<script setup>`
- Props/Emits 严格类型定义
- 通用逻辑提取为 Composables

## 4. API 请求封装方案

### 4.1 Axios 实例配置

```typescript
// api/index.ts
import axios from 'axios'

const request = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL,
  timeout: 10000,
})

// 请求拦截器：添加 Token
request.interceptors.request.use((config) => {
  const token = localStorage.getItem('accessToken')
  if (token) {
    config.headers.Authorization = `Bearer ${token}`
  }
  return config
})

// 响应拦截器：处理 Token 刷新
request.interceptors.response.use(
  (response) => response.data,
  async (error) => {
    const originalRequest = error.config
    if (error.response?.status === 401 && !originalRequest._retry) {
      originalRequest._retry = true
      try {
        await refreshAccessToken()
        return request(originalRequest)
      } catch {
        // 刷新失败，退出登录
        logout()
      }
    }
    return Promise.reject(error)
  }
)
```

## 5. 权限控制机制

### 5.1 路由守卫

```typescript
// router/index.ts
router.beforeEach((to, from, next) => {
  const authStore = useAuthStore()
  
  // 需要登录
  if (to.meta.requiresAuth && !authStore.isLoggedIn) {
    return next('/login')
  }
  
  // 需要管理员权限
  if (to.meta.requiresAdmin && !authStore.isAdmin) {
    return next('/')
  }
  
  next()
})
```

### 5.2 路由元信息

```typescript
{
  path: '/admin',
  component: AdminLayout,
  meta: { requiresAuth: true, requiresAdmin: true }
}
```
