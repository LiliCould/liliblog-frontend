# 立里博客前端重构 - UI 风格规范文档

## 设计哲学

> **摩擦（Friction）与阻抗（Impedance）** —— 承认数字界面的机械本质，通过粗边框、硬阴影、毒性色、噪点与故障，将"人"的不完美与侵略性重新注入界面。
>
> 这套系统的核心不再是"友好"与"流畅"，而是承认数字界面的机械本质。对于年轻用户，这是一种反算法独立的身份宣言——我的博客不是由某种平滑预测模型生成的，它是被设计出来的，带有设计师的脾气与偏见。

---

## 1. 色彩系统：高对比单色系 + 毒性强调色

放弃渐变，采用 Flat Color Blocking（纯色块切割）。

### 1.1 主色（Primary）

| Token | 值 | 用途 |
|-------|-----|------|
| `--primary` | `#4338ca` (Indigo 700) | 主按钮、链接、关键标识 |
| `--primary-foreground` | `#ffffff` | 主色上的文字 |

保持蓝紫底调，完全以平面色块形式出现，不加任何透明度层或渐变蒙版。

### 1.2 毒性强调色（Toxic Accent）

| Token | 值 | 用途 |
|-------|-----|------|
| `--accent-toxic` | `#a3e635` (Chartreuse 荧光黄绿) | Hover、Focus、Active 状态 |
| `--accent-magenta` | `#e11d48` (Hot Magenta 热粉) | 错误、删除、强烈警示 |

这类颜色在数字屏幕上具有物理性的光晕刺激感，是人眼能直接感知的"化学信号"。

### 1.3 绝对中性色（Neutral）

放弃 Slate 的微妙蓝底调，改用更中性的 Stone 系列，或极端化使用纯黑与纯白。

| Token | 值 | 用途 |
|-------|-----|------|
| `--neutral-50` | `#fafaf9` (Stone-50) | 最浅背景 |
| `--neutral-100` | `#f5f5f4` (Stone-100) | 卡片背景 |
| `--neutral-200` | `#e7e5e4` (Stone-200) | 边框、分割线 |
| `--neutral-800` | `#292524` (Stone-800) | 暗色边框 |
| `--neutral-900` | `#1c1917` (Stone-900) | 暗色 Surface |
| `--neutral-950` | `#0c0a09` (Stone-950) | 接近纯黑 |

### 1.4 绝对色

| Token | 值 | 用途 |
|-------|-----|------|
| `--pure-black` | `#000000` | OLED 纯黑背景 |
| `--pure-white` | `#ffffff` | 正文文字 |

### 1.5 应用规则

- 强调色仅用于交互态（Hover、Focus、Active）
- 以几何色块（矩形下划线、方形光标、边框高亮）出现，绝不晕染
- 中性色越绝对，强调色的爆发力越强

## 2. 暗色模式：OLED 纯黑 + 高对比度

去 AI 化需要消除所有半透明与模糊滤镜（Glassmorphism 是算法美学的典型符号）。

### 2.1 暗色模式色值

| Token | 值 | 用途 |
|-------|-----|------|
| `--background` | `#000000` | 页面背景 |
| `--surface` | `#0a0a0a` / `#111111` | 卡片、面板 |
| `--text-primary` | `#ffffff` | 正文 |
| `--text-secondary` | `#a8a29e` (Stone-400) | 辅助文字 |
| `--border` | `#292524` (Stone-800) | 硬边框区分层级 |

### 2.2 层级区分

Surface 与纯黑背景通过 **1px 的硬边框**（`border-stone-800`）区分层级，而非阴影或透明度。

### 2.3 对比度

对比度 ratio 保持在 **15:1 以上**，接近印刷品的油墨密度感。

### 2.4 切换逻辑

- 保留手动切换
- 过渡动画改为**硬切（Hard Cut）**或**故障切换（Glitch Transition）**
- 0ms 或 50ms，拒绝 300ms 的平滑淡入

## 3. 形态系统：极端几何化（Radical Geometry）

年轻化去 AI 审美采用 Neo-Brutalism（新粗野主义）的视觉语法。

### 3.1 圆角规范

| 元素 | 圆角 | 说明 |
|------|------|------|
| 卡片、按钮、图片 | `0px` (rounded-none) | 直角，Neo-Brutalism 语法 |
| 输入框 | `2px` (rounded-sm) | 微圆角，降低攻击性 |
| 标签、徽章 | `0px` | 纯矩形 |

### 3.2 边框规范

| 元素 | 边框 | 说明 |
|------|------|------|
| 卡片 | `2px solid #000000` | 粗外边框 |
| 暗色卡片 | `1px solid #292524` | 硬边框区分层级 |
| 按钮 | `2px solid #000000` | 配合硬阴影 |

### 3.3 硬阴影偏移（Hard Shadow Offset）

不使用 `shadow-lg` 的模糊扩散阴影，而用实体色块的错位投影：

```css
/* 亮色模式 */
.hard-shadow {
  box-shadow: 4px 4px 0px 0px #000000;
}
.hard-shadow:hover {
  transform: translate(4px, 4px);
  box-shadow: 0px 0px 0px 0px #000000;
}

/* 暗色模式 */
.dark .hard-shadow {
  box-shadow: 4px 4px 0px 0px #ffffff;
}
```

Hover 时按钮向上左移动 4px，阴影消失，产生机械按键的物理反馈。

### 3.4 图片处理

- 去掉圆角与阴影
- 采用粗边框包裹
- 可叠加轻微的噪点纹理（Noise Texture）与扫描线（Scanlines），模拟胶片/CRT 的物质磨损

## 4. 排版系统：高密度、粗体、等宽字体混搭

### 4.1 字体栈

```css
/* 正文标题 */
font-family: 'Inter', -apple-system, BlinkMacSystemFont, sans-serif;

/* 元数据、标签、代码 */
font-family: 'JetBrains Mono', 'Fira Code', 'SF Mono', monospace;
```

等宽字体的机械等距感与比例字体的流动感形成字体层面的冲突美学。

### 4.2 字号规范

| 层级 | 字号 | 字重 | 字间距 | 行高 | 用途 |
|------|------|------|--------|------|------|
| Display | 3rem (48px) | 900 (Black) | -0.05em | 1.0 | Hero 标题 |
| H1 | 2.25rem (36px) | 800 | -0.03em | 1.1 | 页面标题 |
| H2 | 1.5rem (24px) | 700 | -0.02em | 1.2 | 区块标题 |
| H3 | 1.25rem (20px) | 600 | -0.01em | 1.3 | 卡片标题 |
| Body | 1rem (16px) | 400 | 0 | 1.625 | 正文 |
| Mono | 0.875rem (14px) | 400 | 0 | 1.5 | 日期、标签、代码 |
| Caption | 0.75rem (12px) | 500 | 0.02em | 1.5 | 辅助信息 |

### 4.3 排版规则

- 标题可故意触碰容器边缘或超出网格，制造排版上的紧张感（Tension）
- 段落间距缩小至 `space-y-4` 或 `space-y-5`，信息密度的压迫感
- 去 AI 化需要信息密度的压迫感，而非算法偏好的大量呼吸留白

### 4.4 链接样式

拒绝下划线动画。使用：
- Hover 时背景变为 Chartreuse，文字反黑
- 或方形括号包裹 `[链接]`，带有代码美学与编辑标记的双重隐喻

## 5. 质感层：噪点、故障与机械误差

在完美数字表面制造人为瑕疵。

### 5.1 全局噪点

在页面顶层叠加一层 `opacity-5` 的噪点 PNG（`pointer-events-none`），模拟胶片颗粒。

```css
.noise-overlay {
  position: fixed;
  top: 0; left: 0; right: 0; bottom: 0;
  pointer-events: none;
  opacity: 0.05;
  background-image: url('/noise.png');
  z-index: 9999;
}
```

### 5.2 故障艺术（Glitch）

- 标题或关键视觉元素可偶尔使用水平错位切片（clip-path 切片）
- Hover 时偏移 2-3px，暗示数字信号的不稳定性

### 5.3 自定义光标

自定义光标为实体色块（如 12px 的 Chartreuse 正方形），替代默认箭头。

### 5.4 加载态

- 拒绝旋转的 Spinner
- 使用打字机效果（字符逐个机械出现）
- 或进度条为实体像素块逐个填充

## 6. 动效哲学：机械感与刚性（Mechanical Rigidity）

### 6.1 Easing 规范

全部使用 `linear` 或 `steps()`，拒绝 `ease-in-out` 的有机平滑。

| 场景 | Easing | 时长 | 说明 |
|------|--------|------|------|
| 所有过渡 | `linear` | 0-50ms | 硬切，拒绝 ease-in-out |
| Hover 位移 | `linear` | 0ms | 瞬时像素级移动 |
| 页面转场 | `steps(5)` | 200ms | 百叶窗式块状切换 |
| 颜色反转 | `linear` | 0ms | 瞬时切换 |

### 6.2 Hover 反馈

```css
.mechanical-hover {
  transition: none; /* 拒绝平滑 */
}
.mechanical-hover:hover {
  transform: translate(2px, 2px);
  background-color: var(--accent-toxic);
  color: var(--pure-black);
}
```

元素位移使用 `transform: translate(2px, 2px)` 的像素级硬移动，配合瞬时的颜色反转（Color Inversion）。

### 6.3 页面转场

不使用淡入淡出，采用硬切 + 轻微的画面抖动或百叶窗式（Venetian Blind）的块状切换。

## 7. 文章渲染样式（Tailwind Typography 定制）

```js
// tailwind.config.js
module.exports = {
  theme: {
    extend: {
      typography: {
        DEFAULT: {
          css: {
            color: 'inherit',
            'h1, h2, h3, h4': {
              fontWeight: '800',
              letterSpacing: '-0.03em',
              lineHeight: '1.1',
            },
            'code::before': { content: '""' },
            'code::after': { content: '""' },
            'code': {
              fontFamily: 'JetBrains Mono, monospace',
              backgroundColor: 'var(--neutral-100)',
              padding: '2px 6px',
              borderRadius: '0px',
            },
            'pre': {
              backgroundColor: '#0a0a0a',
              borderRadius: '0px',
              border: '2px solid #000000',
            },
            'blockquote': {
              borderLeftWidth: '4px',
              borderLeftColor: 'var(--accent-toxic)',
              fontStyle: 'normal',
              paddingLeft: '1rem',
            },
            'a': {
              color: 'var(--primary)',
              textDecoration: 'none',
              fontWeight: '600',
            },
            'a:hover': {
              backgroundColor: 'var(--accent-toxic)',
              color: 'var(--pure-black)',
            },
          },
        },
        dark: {
          css: {
            color: '#ffffff',
            'pre': {
              backgroundColor: '#0a0a0a',
              border: '2px solid #292524',
            },
            'code': {
              backgroundColor: '#1c1917',
            },
          },
        },
      },
    },
  },
}
```

使用方式：

```vue
<template>
  <article class="prose prose-lg prose-slate dark:prose-invert max-w-none">
    <div v-html="article.contentHtml" />
  </article>
</template>
```

- `prose-lg`: 大号正文，适合阅读
- `prose-slate`: 使用 slate 色系，与主色调协调
- `dark:prose-invert`: 暗色模式自动反转
- `max-w-none`: 取消默认最大宽度限制，由容器控制
